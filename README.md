# Christopher Curtis — personal research website

A minimal academic site for **GitHub Pages**, laid out after the [al-folio](https://github.com/alshedivat/al-folio) theme. Plain HTML/CSS/JS: no build step, no frameworks.

## Pages
- `index.html` — about, news, selected publications, contact links
- `publications.html` — all publications by year, with BibTeX
- `projects.html` — research projects and open-source teaching code
- `cv.html` — education, experience, fellowships, teaching, skills

`styles.css` holds all styling (light and dark themes). To change the accent color, edit `--theme` at the top of the file (and the dark-mode `--theme` below it).
